# v0.5.0 — Atera stores

Open MerXen 10x Atera (whole-transcriptome) stores as standalone datasets, with transcript, gene-panel and cell-inspector paths that scale to about 1.4 billion transcripts and 18k genes.

## Atera

- A **Load new standalone Atera dataset** button, `--atera-zarr` and `--atera-spec-path`. Recently viewed remembers Atera stores.
- Detection from MerXen metadata: a store opened through another platform's button, a recent entry or the CLI is re-labelled only when its root `merxen_schema.platform` or `merxen_native_latest.json` says so, with a status-bar message.
- Pixel size from `atera/experiment.spatial` (or the override), else the root `merxen_atera` attributes or the cell-boundary scale, with a warning. A store with none of these is refused.
- The vendor cell outlines load at startup. The nucleus mask is listed once, and a nucleus click selects its cell through `cell_instance_id`. MerXen cell types, the UMAP and per-cell image statistics join on the vendor cells. The vendor masks, label aliases and payload are never modified.
- Transcripts are read lazily from the parquet tiles with pyarrow. **Whole-slide sample** mode (default) keeps a nested sample sized from RAM and fills in the visible field at full density. **Lazy** mode shows a 5 µm density image and reads only the ticked genes. The overview, code-range map, sample and cell-to-tile map are cached outside the store.
- Gene inspector selection mode for Atera and any panel above 2,000 features: search first, up to 32 colour slots, control features folded under one heading, and an all-transcript overview switch.
- Cell inspector without a whole-store index: table counts first, then the cell's exact transcripts (about 0.3 s per cell), capped at 24 pie slices, 200 gene rows and 2,000 links.
- Saved SEA-AD subclass and Allen WHB supercluster predictions are available separately from accepted labels, with a shared bootstrap cut-off for spatial and UMAP colouring. Zero shows every available prediction, including expressed spatial cells outside clustering QC. The cell inspector retains the selected source/type and shows up to five saved candidates; bootstrap support measures stability, not biological probability. Existing assignments and UMAP coordinates are reused.

## Changes

- The gene panel is a virtualised list: a 24.7k-row panel populates in about 0.04 s instead of 224 s.
- The Xenium/MERSCOPE eager transcript build is vectorised (about 5-7 times faster on P7513) with bit-identical output, and no longer fails on stores of 1e9 or more transcripts.
- Paired viewing stays MERSCOPE + Xenium only. An Atera store given to the paired loader is refused before anything is unloaded.
- pyarrow is a declared dependency and is bundled in the installers. The package smoke test round-trips a parquet table.

## Not available for Atera

- Cortical-depth and distance-from-object annotations, and pciSeq sources. Their MerXen exports are defined for MERSCOPE and Xenium, and the disabled controls say so.
- Vendor Azimuth cell types and UMAP (`vendor_azimuth_*`, `X_umap_vendor`): planned as a follow-up.
- A bundled whole-transcriptome marker reference: the gene list is ordered A-Z unless the store embeds one.

See [docs/performance_notes.md](../performance_notes.md) for measured timings and memory use.

## Downloads

Self-contained installers include Python and the viewer dependencies:

- macOS Apple Silicon: `Napari-Compare-Xenium-MERSCOPE-0.5.0-macOS-arm64.dmg`
- macOS Intel: `Napari-Compare-Xenium-MERSCOPE-0.5.0-macOS-x86_64.dmg`
- Windows x86-64: `Napari-Compare-Xenium-MERSCOPE-0.5.0-Windows-x86_64-Setup.exe`
- Debian/Ubuntu Linux amd64: `napari-compare-xenium-merscope_0.5.0_amd64.deb`
- `SHA256SUMS.txt` for verifying downloads.

macOS builds are ad-hoc signed, without Apple Developer ID signing or notarization. macOS may require Gatekeeper approval to open the app.
